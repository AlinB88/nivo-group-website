# NIVO Master Identity

NIVO is the universal mascot and character system behind the future company family.

NIVO is not a single company logo.
NIVO is the recognizable intelligent personality representing the entire group.

Core NIVO characteristics:

- Minimal
- Intelligent
- Friendly
- Professional
- Reliable
- Modern


## NIVO Evolution System

Every future company keeps the same NIVO character.

Do not redesign NIVO.

Companies differentiate through professional accessories or environmental context.

Example:

NIVO Advisory:
- Circular glasses
- Small tie

NIVO Finance:
- Financial-related professional element

NIVO Technology:
- Digital/technology element

NIVO Logistics:
- Navigation/logistics element


The personality must remain recognizable.

# Design Decision Rules

When creating visuals:

Prioritize:

1. Clarity
2. Recognition
3. Long-term scalability
4. Professional credibility


Avoid decisions that only look impressive temporarily.

Every design element must support the future NIVO ecosystem.


---

# Development Philosophy

Technology decisions:

- Prefer simplicity
- Avoid unnecessary dependencies
- Keep performance high
- Use existing solutions before adding packages


Before adding a dependency:

Explain:
- Why it is needed
- What problem it solves
- Whether a native solution exists


Always maintain:

- Clean code
- Clear structure
- Production readiness


---

# Communication Rules

Before major changes:

Explain the plan first.

Do not:
- Create unnecessary files
- Install unnecessary packages
- Change branding assets without approval


Protect:

- NIVO identity
- Brand consistency
- Long-term scalability
